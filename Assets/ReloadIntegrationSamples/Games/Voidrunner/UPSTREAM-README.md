# Voidrunner

A 2D platformer developed with Unity.

## Getting Started

### Prerequisites

* Unity Hub
* Unity Editor **6000.3.24f1**
* Git

### Open the Project

```shell
git clone https://github.com/s10nfault/Voidrunner.git
cd Voidrunner
```

Then open the project through Unity Hub.
