# SRC-01 / 2048 + GoKit

## 来源和本地案例路径

- [B 站推荐出处](https://www.bilibili.com/video/BV1vN4y1G7yL/)；[原仓库](https://github.com/dgkanatsios/2048)，MIT。
- 固定提交：`ed5a74f361bd150444789a142ccee8e34e157409`。
- 完整本地工程：[outputs/test-cases/projects/2048](../../outputs/test-cases/projects/2048/)。
- 场景：[Assets/Scenes/GameScene.unity](../../outputs/test-cases/projects/2048/Assets/Scenes/GameScene.unity)。
- 原工程 Unity 5.6.5f1。下载包含原始工程和许可证；**尚未做 Unity 6 迁移、接入和运行**。

用途是 4×4 棋盘的移动、合并、计分和动画。它比纯 API demo 多了协程与第三方 GoKit 的配合，适合检验“游戏看起来能玩，但第二次 Play 的内部状态是否正确”。
